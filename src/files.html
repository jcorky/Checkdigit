Reference

Local file inspector

Files

Inspect one file in this browser tab. The file is read here, the format is detected from its content, every proposed correction is shown with its evidence, and the corrected file is built from the edits you approve. Nothing is uploaded. Files up to 5 MiB are inspected whole in memory, with near-miss suggestions; larger files, up to 5 GiB, are streamed from disk, their proposals are kept in this site's private browser storage instead of memory, and the corrected file is written back as a stream. That storage is cleared when you discard the job or next open this page.
