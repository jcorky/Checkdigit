Type a container or ILU number (10 characters computes the check digit, 11 verifies it) or a UIC wagon number (11 digits computes, 12 verifies). Each validation layer reports on its own. Nothing you type leaves this page.

ILU codes (EN 13044). Category letters A, B, D, E and K are routed to the ILU set and checked with the same mod-11 arithmetic as ISO 6346. The publisher describes the ILU code as compatible with the BIC code; the check-digit procedure itself has not been verified against the normative EN 13044-1 text, so this is not a claim of normative compliance.
