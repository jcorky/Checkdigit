Check a container number

Check or calculate the check digit for one container, ILU or UIC wagon number. Ten characters calculates the missing digit; eleven checks a complete ISO 6346 number. Every validation layer and the arithmetic are shown below.

Lower case, spaces and hyphens are accepted. For a UIC wagon, enter 11 digits to calculate or 12 to check.

ILU codes (EN 13044). Category letters A, B, D, E and K are routed to the ILU set and checked with the same mod-11 arithmetic as ISO 6346. The publisher describes the ILU code as compatible with the BIC code; the check-digit procedure itself is not independently verified here against the normative EN 13044-1 text, so this is not a claim of normative compliance.
