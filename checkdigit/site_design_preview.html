The check-digit math

The primary scheme is ISO 6346, the standard for container numbers. A number is four letters then six serial digits then one check digit, e.g. MSKU 7351770 — the trailing 0 is the check digit.

Step 1 — letters to values. Map each character: letters use A=10, B=12, … skipping every multiple of 11; digits are themselves.

Step 2 — weight. Multiply position i by 2ⁱ: weights 1, 2, 4, 8, 16, 32, 64, 128, 256, 512.

Step 3 — sum, mod 11. Add the weighted values; take mod 11.

Step 4 — remainder-10 rule. If the remainder is 10, the check digit is 0; otherwise it is the remainder.

sum = 11321 → 11321 mod 11 = 0 → check digit 0 → MSKU7351770 ✓
Byte-splice, never re-serialize. CHECKDIGIT parses to locate the identifier's exact byte offset, then replaces only the wrong digit's bytes. It never rebuilds the file — so terminators, encoding, quoting, and every untouched field come back exactly as sent.
