Where the user views the physical representation

After correcting a BAPLIE, rail, or truck file in the Correct view, a Stowage panel appears directly beneath the results — built from the corrected container numbers. Vessel files get a tab per bay; rail and truck get one diagram. Below is that panel for a sample BAPLIE (vessel MAERSK ALABAMA), with three check digits already corrected upstream.

⌅ Vessel bay plan MAERSK ALABAMA built from the corrected file

Drawn from the corrected container numbers. Hover any unit for its detail. Reefer, hazmat, oversize, high-cube and empty are flagged; an unrecognized size/type is shown grey rather than guessed.

The same render is available headless at POST /visualize (returns the SVG), and the Docs → Stowage visualizers section explains the honesty rule: rail/truck positions not carried in EDI are drawn dashed and marked inferred.
