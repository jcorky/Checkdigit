What it does

Four steps, nothing guessed

Each identifier is validated against the standard it actually uses. When the type is ambiguous or a local override might apply, CHECKDIGIT flags it instead of silently rewriting it.

01

Detect

Reads EDIFACT, X12, SNX XML, CSV, fixed-width, XLSX, or plain text by content — and finds every equipment ID inside.

02

Route

Sends each ID to the right algorithm: ISO 6346 mod-11 for containers, the matching scheme for ILU and UIC. Never the wrong one.

03

Correct

Recomputes the check digit and splices the correct character in by byte offset. Every other byte in the file is left exactly as it was.

04

Review

Shows a before/after diff of precisely what changed, and records each run so you can see what came through.

Coverage

It reads your files as they are

Corrected output comes back in the original format, byte-for-byte identical except at the digits that were wrong.

The audit log keeps file name, type, size, time, and verdict counts. It never records an IP address.

Enrichment is opt-in

Owner and box lookups stay switched off until you configure them. Nothing phones out on its own.
